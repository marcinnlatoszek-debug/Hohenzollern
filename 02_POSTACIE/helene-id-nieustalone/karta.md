# Helene (Helena) — osobista lekarka Hohenbergu — CK3 ID 52665 (pierwotna karta ekranowa)

**Uzgodnienie 11 X 2026:** ID **52665** potwierdzone w save’ach 20 X i 16 XI; lekarka od 17 X. [Aktualna karta i rozszyfrowane cechy](../52665/karta.md). Starsze oznaczenia ID, daty przybycia i traitów jako NIEUSTALONE opisują etap sprzed tego odczytu. Ścieżkę zachowano dla istniejących linków.


**Status:** ROZPOZNANA_SCREEN, ID **NIEUSTALONE**. Robocza karta bez przypisania do dowolnego numerycznego ID. **Źródło:** dwa obrazy z rozgrywki z 11 X 2026; nazwa eksportu portretu podaje **20 X 1066**. Na samych ekranach nie ma niezależnego kalendarza gry.

## Obserwacje potwierdzone na karcie postaci

- Imię w interfejsie: **Helene** (polska forma redakcyjna: Helena).
- Wiek na ekranie: **31 lat**; płeć: kobieta.
- Funkcja: **Your Personal Physician** — osobista lekarka Burkharda von Hohenzollern (nie potwierdzono, od kiedy sprawuje urząd).
- Dwór: **At your Court in Hohenberg**.
- Pochodzenie: **Lowborn** (nie jest to nazwisko ani dynastia).
- Kultura: **Swabian**; obrządek: **Roman Rite**.
- Status: **Unlanded** (bezziemna).
- Podsumowanie osobowości interfejsu: **Fearless Maniac**. **Nie traktować jako listy trzech indywidualnych cech CK3 ani diagnozy medycznej.**
- Umiejętności końcowe z karty (DIP / MAR / STE / INT / LEA / PRO): **0 / 8 / 6 / 9 / 16 / 1**.
- Opinia wyświetlana przy postaci / seniorze: **+2**; bez osobnego tooltipu nie rekonstruować szczegółowych modyfikatorów.
- Złoto **50**, prestiż **300**, pobożność **51**.
- Na panelu: **Family 0, Relationships 0, Courtiers 0**, **Children (0)**, **Siblings (0)**. Pola rodziców/pra-dziadków puste. „Find Spouse” przy pustym miejscu małżonka, ale nie przesądzać historii jej związków.
- Na ekranie widocznych jest **pięć ikon cech**. Bez potwierdzonego tooltipu lub rekordu save’a ich tożsamość i stopnie pozostają **NIEUSTALONE**.

## Chronologia i granice wiedzy

W repozytorium bazowym znajduje się indeks **112 wybranych własnych rekordów** z `von_Hohenzollern(2).ck3`, stan **18 IX 1066**; Helene nie figuruje w tym indeksie. Nie wynika stąd pewnie, że nie występowała w świecie gry 18 IX — indeks nie obejmuje wszystkich żyjących postaci. Data pozyskania lekarki, data jej przybycia na dwór, data urodzenia oraz wewnętrzny CK3 ID wymagają sprawdzenia w save z **20 X 1066** (lub tooltipie/debug char ID).

**Zasada ciągłości:** nie cofać jej funkcji do scen z 18 IX bez źródła wskazującego, że już wtedy była na dworze. Nowszy screen nie potwierdza wcześniejszego urzędu.
